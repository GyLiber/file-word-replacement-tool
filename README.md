# File Word Replacement Tool

A command-line utility for replacing words in one or more text files and
writing the processed files to an output directory.

The tool was developed as a GyLiber project to support modification of
compiler test-case files for similar languages.

## Status

Version 1.0.0 — in development.

## Requirements

- Python 3.10+
